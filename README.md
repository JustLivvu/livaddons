# LivAddons (This mod works only on Hypixel)

**LivAddons** is a feature-packed Minecraft Fabric mod focused on improving the Hypixel SkyBlock experience. It includes a wide range of Dungeon utilities, quality-of-life features, and synchronized cosmetics that are shared with other LivAddons users.

All cosmetics are automatically synchronized and visible to any other players running the LivAddons mod.

# Features

## General
- **Copy Chat** — Copy messages directly from chat.
- **Party Commands** — Custom party commands (`!w`, `!pt`, etc.).

## Dungeons
- **Highlights** — Highlight starred mobs in dungeons.
- **Lava to Water** — Replace lava textures with water (helpful in Floor 7 and Master Mode 7).
- **Diorite to Glass** — Replace Diorite and Polished Diorite textures with gray glass (helpful in Floor 7 and Master Mode 7).
- **Dungeon Finish Song** — Play **EZ4ENCE** when a dungeon is completed.
- **Leap Alert** — Send a chat message whenever you leap to another player.
- **Dungeon Map** — Built-in dungeon map (ported from Odin).
- **Room Clear** — Notify when a room is cleared or completed (ported from Odin).

### Floor 7
- **Terminal Waypoints** — Display waypoints for terminals. Waypoints disappear after the terminal is completed.
- **Terminal Solver** — Solve every terminal except Melody.
- **Melody Alert** — Automatically send a party chat message when opening the Melody terminal.
- **Terminal GUI** — Display the current terminal progress for each phase.
- **3x3 Highlights** — Highlight the blocks that need to be broken during Necron's phase.

## Render
- **Disable Fire** — Hide fire overlay textures while you are on fire.

## Cosmetics
- **Custom Nicknames** — Customize your display name.
- **HEX Color Gradients** — Create colorful nickname gradients using custom HEX colors.
- **Text Formatting** — Toggle bold and italic formatting.
- **Dynamic Player Height** — Change your visual player height.
- **Real-Time Synchronization** — Cosmetics are synchronized between LivAddons users.

## Miscellaneous
- **Click GUI** — Customize GUI colors.
- **GUI Positions** — Freely move the Dungeon Map and Terminal GUI.

# Installation

1. Install **Minecraft 1.21.6**.
2. Install **Fabric Loader** (`0.15.0+` or newer).
3. Download the latest **LivAddons** release.
4. Place the `.jar` file into your `.minecraft/mods` folder.
5. Launch Minecraft, join **Hypixel**, and run `/livaddons`.
