# LivAddons (This mod works only on Hypixel)

**LivAddons** is a feature-packed client cosmetics mod for Minecraft (Fabric). It allows you to customize your display username with vibrant HEX color gradients, toggle text formatting (**Bold** / *Italic*), and dynamically adjust your character's visual height in real-time.

All cosmetics are automatically synchronized and visible to any other players running the LivAddons mod!

## Features

- **Custom Nicknames & HEX Gradients** — Personalize your display name using custom start and end HEX color gradients with optional bold and italic styles.
- **Dynamic Visual Height** — Adjust your character model height on the fly (from 0.5x to 2.0x) using an intuitive in-game slider.
- **Nametag, TAB List & Chat Integration** — Custom names, colors, and styling are rendered above your head, in the TAB list, and in chat messages.
- **Real-Time Sync** — Cosmetic updates sync automatically across all active LivAddons users.
- **In-Game Customization Menu** — Configure all cosmetics easily with a clean, built-in graphical interface.

---

## Commands

- `/livaddons` — Opens the LivAddons GUI menu to edit your nickname, color gradient, font styles, and player height.

---

## Installation

1. Make sure you have **Minecraft** (26.1.2) and **Fabric Loader**  installed.
2. Download the latest `livaddons.jar` file.
3. Place the file into your `.minecraft/mods` directory.
4. Launch Minecraft, join a world or server, and type `/livaddons` to start customizing!
